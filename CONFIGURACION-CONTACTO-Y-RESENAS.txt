CONFIGURACIÓN DE CONTACTO Y RESEÑAS — LETWELVE

CONTACTO
El formulario ya apunta a 12letwelve12@gmail.com mediante FormSubmit.
1. Publica la web en un hosting con HTTPS.
2. Envía un primer mensaje de prueba desde contacto.html.
3. FormSubmit enviará un email de activación a 12letwelve12@gmail.com.
4. Abre ese correo y confirma la activación. Hasta entonces no se garantiza la recepción.
5. Vuelve a probar el formulario.

RESEÑAS PÚBLICAS
La sección está preparada, pero requiere una base de datos gratuita Supabase:
1. Crea un proyecto en https://supabase.com/
2. En SQL Editor ejecuta:

create table public.reviews (
 id bigint generated by default as identity primary key,
 name text not null check (char_length(name) <= 60),
 rating int not null check (rating between 1 and 5),
 review text not null check (char_length(review) <= 1000),
 approved boolean not null default false,
 created_at timestamptz not null default now()
);
alter table public.reviews enable row level security;
create policy "Anyone can read approved reviews" on public.reviews for select using (approved = true);
create policy "Anyone can submit reviews" on public.reviews for insert with check (approved = false);

3. En Project Settings > API copia Project URL y anon/public key.
4. Sustituye los valores PON_AQUI en js/config.js.
5. Revisa reseñas en Supabase y cambia approved a true para publicarlas.

AVISO POR EMAIL DE RESEÑAS
El formulario de reseñas también envía una copia a 12letwelve12@gmail.com mediante FormSubmit y la guarda en Supabase. El primer uso requiere activar FormSubmit desde el email de confirmación. Para que las reseñas se publiquen, además hay que configurar Supabase y aprobarlas. Ninguna clave privada se coloca en el navegador.

IMPORTANTE
- Las reseñas quedan pendientes de aprobación antes de mostrarse públicamente.
- El carrito guarda artículos en el navegador del visitante.
- El checkout/pago real sigue pendiente de conectar.
